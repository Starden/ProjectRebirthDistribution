# Rebirth content 0.1.36

Heritage progress now refreshes while Reverie is open after a confirmed award.
The server sends progress after a verified save and no longer inserts a one-second
wait before each successful database step. The 10% share retains fractional carry;
character-only experience bonuses remain separate. Previously earned XP is kept.

Claude's 768x500 panel revision adds full-width progress bars, racial portraits,
clearer level descriptions and taller Glossary rows. The menu keeps its spacing
when the keyring button is hidden.

Use **Update** for Rebirth in launcher **2.3.1**. Your locally prepared heirloom
data is preserved. The launcher binary and Skillful content are unchanged.

Dynamic open-world respawns are being implemented and are not enabled by this
client update. The nine additional racial effect sets remain design previews.
Live visual and kill-to-display timing checks are still pending.
