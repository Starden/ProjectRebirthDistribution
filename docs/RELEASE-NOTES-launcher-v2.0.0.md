# Project Reverie Launcher 2.0.0 — A new horizon

The new Void and Moonstone design brings the Project Reverie emblem, clearer
status panels, and a prominent Play area to Rebirth. Choose Follow Windows,
Void, or Moonstone in Settings → Appearance. Changes save immediately. Fullscreen
remains visible beside Play on every page. Windows high contrast takes precedence.

Content is now **0.1.30**, following legacy content **1.30.0**. A signed generation
field makes that transition an upgrade while retaining rollback protection.
This release does not change gameplay, accounts, native client data, or the server.
Existing client selections, settings, and completed item-cache refreshes survive.

From launcher **1.6.3 or newer**, accept **Update and restart** inside the launcher.
Versions **1.6.2 or older** need the complete new ZIP extracted once into a fresh
regular writable folder separate from WoW. Never run the launcher from inside the
ZIP. New-generation content requires launcher 2.0.0.

The four-file package embeds its updater, artwork, and OFL-licensed Inter and
Cormorant Garamond fonts. Support → Credits and font licenses includes notices.
No additional runtime, VPN, base-game download, or external updater is required.
Bring your own lawful clean ChromieCraft 3.3.5a client and an approved account.

ECDSA-signed HTTPS feeds, archive and payload SHA-256 checks, staged replacement,
backup recovery, and the original trust key remain in use. The executable is not
yet Authenticode-signed; Windows may still show Unknown Publisher.
