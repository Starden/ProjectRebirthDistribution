# Project Reverie Launcher 2.2.0

Choose **Skillful** or **Rebirth** before opening WoW. Skillful now has its own signed addon feed and public gateway; existing player accounts have access with their existing credentials. Accounts that already existed on Skillful retain their Skillful password.

Skillful's **Prepare Client** builds and verifies Hero, ranged-attack and Bottle of Experience data locally from your own clean English enUS 3.3.5a client. Use a separate client folder for each game. Original game archives stay unchanged, and unknown custom patches are preserved and refused.

Select Skillful, locate its separate clean client, choose **Update** for the addons, close WoW, choose **Prepare Client**, then **Play Skillful**. Players need no VPN or separate patcher. The launcher supplies no game client or Blizzard archives.

Launcher 2.2.0 is required for the Skillful feed. Existing launchers offer a verified update to 2.2.0; if an old copy cannot update, extract the complete latest ZIP into a fresh writable folder outside WoW. Client selections and preferences carry over. Rebirth content remains 0.1.34 with its existing payloads and preparation.

Validation covered the real packaged 2.1.0-to-2.2.0 updater, successful replacement and failure recovery, settings preservation, signed feed verification, client preparation/readback, unknown-patch refusal, launcher button states and the public package inventory. Gameplay remains in testing.
