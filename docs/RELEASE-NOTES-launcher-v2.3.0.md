# Project Reverie Launcher 2.3.0

Skillful now has **Goldleaf**, a burnished gold and deep forest appearance. Choose
**Settings → Appearance → Follow Realm** to use Void for Rebirth and Goldleaf for
Skillful. The palette changes as you select a game. Follow Windows, Void and
Moonstone remain available, and your existing preference is retained.

Both game cards now use the owner's painted emblems: a phoenix for Rebirth and a
gold shield with sword and pickaxe for Skillful. Each card carries a larger, subtle
watermark of its emblem. The header retains Project Reverie's emblem.

Existing launchers offer a signed update to 2.3.0. Choose **Restart to update** when
ready. Your selected client folders and preferences carry over. If an old launcher
cannot update, extract the complete new ZIP into its own writable folder outside WoW.

Rebirth content remains 0.1.34 and Skillful addon content remains 0.12.1. Existing
client preparation stays valid. This launcher update changes no gameplay or
profession requirements. Use a separate lawful English enUS WoW 3.3.5a build 12340
client for each game. The package contains no game client or Blizzard archives.
