# Launcher 2.0.3 / Content 0.1.34 - The full non-Monarch Heritage roster

This release supplies the matching client definitions for ten additional
Heritages: Dragonkin, Celestial, Undying, Beastkin, Titanborn, Void-Touched,
Elemental, Lich, Werebeast, and Spiritbound. Paragon, Enlightened Human, Vampire, and Demonic
remain available. World Difficulty, Hunts, and Monarch are not included.

After the matching server rollout, eligible players are prompted to choose
their Heritage again once, without a Rebirth. Character levels, the current
Life, Skills, and equipment are preserved. Persistent Heritage progress is
retained; current-Life-only progress is restored only within the same Life.

The Heritage menu includes complete effect descriptions and growth ranges,
and click-select Dragonkin lineage and Elemental attunement options. Aspect changes must be
confirmed by the server and require a safe resting area or sanctuary.

## Update

1. Update the launcher to **2.0.3**.
2. Close WoW and update content to **0.1.34**.
3. Select **Prepare Client** when prompted, then play.

Native data are generated locally from your own clean English 3.3.5a client.
Existing supported native versions upgrade automatically with recoverable
backups. Original game archives, existing item/Heirloom data, and saved settings
are preserved. Unknown or modified patches are refused, not overwritten.

The **five-minute updater validation timeout** introduced in 2.0.2 is retained.
If an older launcher cannot update, close it and extract the complete 2.0.3 ZIP
into a fresh regular folder outside WoW. Do not bypass fingerprint warnings.

These systems are playable alpha content; balance and in-game compatibility
remain subject to tester feedback. Installing the client does not itself
activate server features. Account-access rules have not changed.
