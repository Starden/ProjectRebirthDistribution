# Project Reverie Launcher 1.2.0 — Rebirth identity update

Project Reverie is now the umbrella project identity. **Rebirth** remains the
exact realm/server name, and this launcher release continues to target only that
realm.

This release adds:

- the project-owner-supplied proprietary Project Reverie mark in the launcher
  header and executable icon;
- signed content 1.5.0 with Rebirth progression addon 1.7.0;
- the same mark in the Rebirth progression header, lifecycle page, and bottom
  micro-menu button;
- the existing independent Rebirth Wardrobe 1.0.1 unchanged; and
- continued HTTPS/ECDSA verification of every managed file.

Players still need only this launcher ZIP and their own lawful, clean
ChromieCraft WoW 3.3.5a build 12340 client. The archive contains no WoW client,
MPQ, credential, VPN profile, or signing private key.
