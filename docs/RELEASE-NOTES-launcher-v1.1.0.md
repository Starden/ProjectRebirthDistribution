# Project Rebirth Launcher 1.1.0 — Rebirth Wardrobe

This launcher expands the signed managed-content boundary to exactly two Project
Rebirth-owned addons: `ProjectRebirthTooltips` and `RebirthWardrobe`. It still
requires a lawful, clean ChromieCraft 3.3.5a client and does not include WoW,
MPQs, credentials, VPN profiles, or signing keys.

Included:

- strict two-addon path allowlist with traversal and reparse-point rejection;
- signed content 1.4.0 containing Rebirth progression UI 1.6.3 and Wardrobe 1.0.1;
- account-wide cosmetic collection UI, persistent slot appearances, outfits, and
  talent-spec bindings;
- the established public gateway at `134.122.124.150:3724` and `:8087`;
- ECDSA P-256 manifest verification and per-file SHA-256/size verification.

The Wardrobe is cosmetic and independent from Rebirth Life, Skill, Heritage,
Manifestation, item-upgrade, and PlayerBots progression.
