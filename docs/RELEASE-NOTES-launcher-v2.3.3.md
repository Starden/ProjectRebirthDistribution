# Project Reverie launcher 2.3.3

Settings adds a local icon-library selector for Rebirth and Skillful. Classic Icons remains the default for existing clients; Updated Icons is optional. An icon name without a verified stock classic counterpart always uses the imported updated image. Import the supplied archive locally, close WoW and apply the desired mode. Selections are stored per client folder. Supplied textures remain private and are excluded from the launcher ZIP and public feed.

Import and Apply now keep the launcher window open until the operation completes, including error cleanup. Normal Play and launcher self-update closing behavior remains available. Private managed icon files do not cause the signed addon assessment to offer Repair. The launcher uses normal Update for newer Rebirth content 0.1.37, with epoch 1 retained.

The four-file ZIP, real packaged trust/content/feed paths, native recipe resources, synthetic native MPQ roundtrip and embedded updater have been tested. Actual client rendering of the imported textures remains a player check; operating-system forced termination is outside the window close guard.
