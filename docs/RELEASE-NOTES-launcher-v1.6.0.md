# Launcher 1.6.0 / Rebirth content 1.28.0

- Fourth-specialization and Feral Cat interface with configurable alpha talent values.
- Native preparation builds the required data locally from your own approved 3.3.5a client; no game archives are downloaded.
- Existing Skill descriptions, currencies, upgrades, Heirloom UI and locally generated Heirloom data are preserved.
- Account permissions are unchanged. Fourth-specialization server activation is a separate controlled rollout.

Download the ZIP, close the old launcher, extract into a fresh folder and run
ProjectReverie.Launcher.exe. Your selected client is retained. Use Check Updates,
Update, and Prepare Client when offered. Close WoW before preparing native files.
Do not delete original game archives or replace an unrecognized custom patch.

This remains an alpha. Values are configurable and will change during testing.
The local installer passed 74 fourth-spec checks, 35 onboarding checks and 23
existing native-data checks, including fresh preparation, an existing-client
upgrade, repeat preparation and refusal to overwrite unknown data. Independent
archive extraction verified all six generated table hashes. The public package
and signed owned-content feed passed 130 checks.

These checks do not certify every talent or ability in live combat. Server
activation and in-game alpha testing follow the separate deployment checks.
