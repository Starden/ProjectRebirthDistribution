# Rebirth content 0.1.37

Requires Project Reverie launcher **2.3.3**. Use the normal **Update** action, close WoW and run **Prepare Client** when prompted. The content version advances within epoch 1; existing managed addons and the private locally generated Heirloom tooltip catalog remain intact.

Rebirth now includes the reviewed nameplate presentation: rank badges, numeric levels, threat tint and cast decorations. `/rplates scale 1.5` changes their size. Native health, targeting and combat behavior are unchanged. Name-only matching and a table fallback cannot reliably distinguish every same-named creature or player; live crowd/rendering validation remains pending.

The coordinated server candidate fixes the Deadmines ownerless spell-modifier crash, corrects Holy Archer unlock and native Auto Repeat handling, and adds the Long Arm range packet/client metadata. Newly provisioned bots receive the approved complete heirloom kit and four crate bags. Dynamic respawn support is included with its existing default disabled; an initial observation rollout and later activation are operator-controlled. No live Dynamic acceleration is claimed by this release preparation.

Heritage progress updates, the Human Bloodline, retired Paragon history, Bot Manager and the existing panel remain supported. Wardrobe remains removed. This release does not introduce the other nine racial Bloodline runtime effects.

Operator release checks still must confirm the exact installed native candidate, character backup/reset/refill, startup and configured rollout mode before signing and activating these prepared files. Those live checks were pending when this unsigned candidate was prepared. No reset or refill is inferred from the build tests.

Launcher 2.3.3 also offers the private local icon library in Settings for either game. This does not add textures to the signed 49-file Rebirth feed or change the Skillful feed.
