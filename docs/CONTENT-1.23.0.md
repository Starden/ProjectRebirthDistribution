# Rebirth content 1.23.0

Requires launcher **1.3.0** or later. This is a content-feed release; the launcher
executable is obtained separately from the operator. Earlier launchers cannot
install this feed.

Includes the currently deployed Rebirth UI, searchable Skill glossary, fourth-spec
talent artwork and upgrade-anvil comparison window, plus the independent Wardrobe.
All 28 files are Rebirth-owned addon code or supplied artwork. The native client
data is not part of this download; existing testers need the matching local data.
The portable native-data installer and mandatory first-login password-change flow
remain separate unfinished work. No game archive, database dump, credential or
private signing key is included.

The signed manifest and its payload deploy together as one validated Pages artifact.
The server, gameplay feature gates, characters and networking are unchanged.
